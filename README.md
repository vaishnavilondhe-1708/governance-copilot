# Governance Copilot

AI Governance & Risk Management Platform for Banking.

## Objective

Governance Copilot helps organizations evaluate, monitor, and govern AI models used in banking.

## Key Areas

- AI Risk Assessment
- Fairness Analysis
- Explainability
- Privacy Checks
- Governance Scoring
- Human Oversight
- Audit Trails
- AI Governance Copilot

- SQLAlchemy
- PostgreSQL
- React
